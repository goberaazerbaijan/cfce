# Cambridge FCE Platform (cfce)

Bu layihə Cambridge FCE imtahan hazırlıq platformasının yeni, təhlükəsiz versiyasıdır.

## Xüsusiyyətlər
- Backend Proxy arxitekturası (API açarları gizlidir)
- Admin və Marker panelləri
- Real vaxtda nəticə izləmə
- PDF-dən sual yükləmə dəstəyi

## Qurulum
1. `cfce-backend` repository-sini Render-də deploy edin.
2. `app.js` faylında `API_URL` dəyişənini Render URL-inizlə dəyişin.
3. Bu faylları GitHub Pages ilə yayımlayın.
